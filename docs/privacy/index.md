# Privacy Policy

**FlashMash** ("the App") is developed and operated by Omoiyari-Works ("we", "us", or "our"). This Privacy Policy explains how we collect, use, and protect information when you use the App.

---

## 1. Consent

We collect usage data only **after you explicitly agree** to data collection at the time of your first app launch. You may decline at any time, and no data will be collected.

---

## 2. Information We Collect

We collect the following information **only when you have given consent**:

### 2.1 Usage Analytics (Firebase Analytics)

We collect anonymized event data to understand how the App is used, including:

- Clip operations (add, delete, split, move, copy, paste, crop)
- Audio effect usage (time stretch, pitch shift, FX slot changes, loop settings)
- Track operations (add, delete)
- Project settings (BPM changes, grid resolution)
- Playback actions (play/pause)
- Edit history actions (undo, redo)
- Error events (e.g., failed cloud write attempts)

### 2.2 Project Snapshots (Firebase Firestore)

We periodically save a snapshot of your project's structural metadata to our cloud database, including:

- Track and FX slot configuration (type and enabled/disabled status)
- Clip parameters (time stretch settings, pitch shift amounts, number of clips)
- Project duration and BPM
- Timestamp of snapshot

**Audio files themselves are never uploaded.** Only project structure and settings metadata are stored.

### 2.3 In-App Survey Responses (Firebase Firestore)

After several app launches, the App may ask for your feedback. If you respond, your answer (a satisfaction level selection) and the submission timestamp are stored. Participation is voluntary.

### 2.4 Crash Reports (Firebase Crashlytics)

When the App crashes, diagnostic information including device state, stack trace, and error details are collected to help us fix bugs.

---

## 3. How We Identify You

You are assigned an **anonymous user ID** via Firebase Anonymous Authentication. This ID is randomly generated and is not linked to your name, email address, or any other personal information.

---

## 4. How We Use Your Information

We use collected information solely to:

- Improve app stability and fix bugs
- Understand which features are used and how
- Prioritize future development

We do **not** use your information for advertising or sell it to third parties.

## 6. Data Storage and Security

- All cloud data is stored in Firebase (Google Cloud), protected by Firestore security rules that restrict access to your anonymous user ID only.
- No other user can read your data.
- Data collection is **disabled by default** and enabled only after you consent.
