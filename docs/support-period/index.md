# Security Update Support Period

This page publishes the security update support period for **FlashMash** ("the App"), developed and operated by Omoiyari-Works ("we", "us", or "our"), in accordance with Article 13(11) of Regulation (EU) 2024/2847 (the Cyber Resilience Act, "CRA").

---

## 1. Support Period Policy

For each release of the App, we provide security updates for a minimum of **one year** from the date that release becomes available. Beyond that minimum period, we continue to provide security updates for as long as active development of the App continues.

---

## 2. Scope of Support

The "support" described on this page refers specifically to **security updates** — fixes addressing vulnerabilities that could affect the safety or security of the App or its users. It does not constitute a guarantee that we will continue to add new features, provide general (non-security) bug fixes, or maintain compatibility with new operating system versions.

---

## 3. Current Status

As of the date this page was published, **no version of the App has an announced end of security update support.**

---

## 4. How End of Support Will Be Announced

If we decide to end security update support for a specific version of the App, we will not create a separate announcement page. Instead, we will update **this page** directly, adding:

- The affected version(s)
- The date on which security update support ends
- Whether a successor version is available and, if so, how to migrate to it

Please refer back to this page to check the current security update status of the version you are using.

---

## 5. Reporting Vulnerabilities

If you discover a security vulnerability in the App, please report it to us using the contact information below.
