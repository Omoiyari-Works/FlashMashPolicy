# EU Declaration of Conformity

This EU Declaration of Conformity is issued in relation to the requirements of Regulation (EU) 2024/2847 (the Cyber Resilience Act, "CRA") for **FlashMash** ("the App"), developed and operated by Omoiyari-Works ("we", "us", or "our").

---

## 1. Product

- **Product name:** FlashMash (FlashMashApp)
- **Package name:** `com.omoiyari_works.flashmash`
- **Product type:** Android audio mashup production application (mobile DAW)
- **Applicable versions:** The latest release publicly available as of the issue date of this declaration, and all subsequent releases. This declaration continues to apply to later minor and patch updates unless a significant change to the security design occurs (for example, a new feature that requires the conformity assessment route to be reassessed).

## 4. Object of the Declaration

The object of the declaration is the product identified in Section 1 above: FlashMashApp, package name `com.omoiyari_works.flashmash`.

## 5. Declaration of Conformity

The object of the declaration described in Section 4 above is in conformity with the relevant requirements of Regulation (EU) 2024/2847 (Cyber Resilience Act). The conformity assessment was carried out under the self-assessment procedure set out in Annex II (Module A, conformity based on internal control), based on the determination that the product does not fall under either important product class I or class II of Annex III.
